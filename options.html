Tab switching settings

Move through recently used tabs with Back and Forward shortcuts. Hold the shortcut to choose a tab from a list.

01

Shortcuts

Choose Change or Add, then press the key combination you want to use. You can assign multiple shortcuts to each action. Press Esc to cancel.

Control is the physical Control key (⌃). Meta is the Command key (⌘) on macOS or the Windows key on Windows. Esc, Tab, Enter, and arrow keys are reserved for navigation. Some keys are handled by Chrome or the OS before this extension receives them.

Assignments from Chrome's shortcut settings are kept separately. The default J/K combinations are the same, and shortcuts configured here are saved in this extension's settings.

02

Behavior and history

seconds

Choose 0.5–2.0 seconds in 0.1-second increments.

tabs

Keep and show 10–30 past tabs in addition to the current tab. Reducing the limit removes older entries. Increasing it starts retaining additional history from then on. The tab-order list shows all tabs in the current window.

03

Tab list display

The extension detects keys on regular web pages and shows tab titles and favicons in the long-press list. Allow access to the sites where you use it.

Checking site access.

Use shortcuts while a regular web page has focus. Chrome internal pages, the Chrome Web Store, and the address bar have input restrictions.

How it works

  • Press and release before the hold duration to move one tab Back or Forward. Navigation stops at the ends of the history.
  • Hold the modifier keys and the assigned regular key together to show MRU candidates.
  • In the list, use Up and Down to select, Enter to switch, and Esc to cancel. Left switches between MRU and tab order. Right has no action.
  • In tab order, type text to filter tab titles. Press Backspace to delete the last character. Search is case-insensitive and uses tab titles.
  • Holding only the modifier keys after releasing a regular key such as J or K does not count as a long press.
  • Each tab appears once, ordered by recent use.
  • Selecting another tab normally ends the current traversal.
